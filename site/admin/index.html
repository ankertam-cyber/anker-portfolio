連接 GitHub

連接後可以直接發佈到你現有嘅 GitHub Pages 網站。

  1. 喺 GitHub 建立一個 fine-grained token，選擇資源擁有人 ankertam-cyber。
  2. Repository access 選 Only select repositories，只揀 anker-portfolio。
  3. Contents 設為 Read and write；Actions 設為 Read-only。Metadata 會自動包括。
  4. 將 token 貼喺下面，撳「連接」。
開啟 GitHub 設定

Token 只喺呢個分頁嘅記憶體使用，唔會儲存到草稿、網站或網址；重新整理後需要再連接。
